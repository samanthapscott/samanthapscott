### Stack and Queue Visualizer

An interactive desktop GUI application built in **C++** with **wxWidgets** that provides real-time visualization of Stack (LIFO) and Queue (FIFO) data structures. Supports push, pop, enqueue, and dequeue operations with live display updates and input validation.
