### DriveSense — Biometric Steering Wheel
![ESP32](https://img.shields.io/badge/ESP32-7C3AED?style=flat-square) ![Raspberry Pi](https://img.shields.io/badge/Raspberry%20Pi-A22846?style=flat-square) ![React Native](https://img.shields.io/badge/React%20Native-3B82F6?style=flat-square&logo=react) ![TypeScript](https://img.shields.io/badge/TypeScript-3178C6?style=flat-square&logo=typescript) ![Supabase](https://img.shields.io/badge/Supabase-3ECF8E?style=flat-square&logo=supabase&logoColor=black)

**FIU Senior Design team project** combining biometric sensing, embedded electronics, wireless communication, and a mobile app for driver monitoring.

- Developed and tested a React Native/TypeScript application with biometric telemetry, driver profiles, emergency contacts, and safety-oriented workflows.
- Developed and tested ESP32 firmware for multi-sensor MAX30102 PPG acquisition using a TCA9548A I2C multiplexer.
- Integrated Supabase data and telemetry features and contributed to ESP32, Raspberry Pi, and mobile interface work.
- Developed **Sensi**, a voice-enabled assistant with on-device language-model inference and speech recognition.
- Latest recorded automated validation: **773 passing tests**. End-to-end physical and emergency workflow validation is tracked separately.

### Traffic Light Controller with Pedestrian Interface
![Zybo Z7](https://img.shields.io/badge/Zybo%20Z7-3B82F6?style=flat-square) ![VHDL](https://img.shields.io/badge/VHDL-7C3AED?style=flat-square) ![Vivado](https://img.shields.io/badge/Vivado%2FVitis-0B0920?style=flat-square)

Designed and deployed an FPGA-based traffic controller using a VHDL finite-state machine, pedestrian input handling, timed state transitions, and OLED countdown feedback. Tested the design on Zybo Z7 hardware.

### Raspberry Pi Linux Server Monitor
